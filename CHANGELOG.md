## 0.1.0a1 — 2026-11-04

First public alpha of RotorVibe, released from an existing local research workspace.

- Publish the synchronous NumPy analysis core and stream contracts, bearing geometry,
  replaceable providers, stages/sinks and optional local monitoring application.
- Retain Gaussian, normal-first, RPM-conditioned and morphology diagnostic algorithms
  as experimental APIs with explicit applicability and abstention semantics.
- Add the `rotorvibe` facade while preserving the `vibration` compatibility namespace.
- Document the complete experimental sequence, including failed cross-speed,
  cross-bearing and independent-rig validation. No universal accuracy claim is made.
- Publish authored metric/protocol/prediction/access evidence without raw measurements
  or trained rig-specific profiles.
- Exclude private standard tables/selectors/fixtures and replace the public rule route
  with explicit caller-supplied limits and synthetic verification examples.
- Supply an original README, operating guide, algorithm notes, module catalog,
  development record, continuation handoff, rights inventory and citation metadata.
- MIT applies to original code and authored documentation; external source terms remain.

The private local studies preceded public Git history. See the development record
for that reconstructed chronology rather than interpreting this one release commit
as a complete history of earlier experimentation.
