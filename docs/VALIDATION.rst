GitHub 업로드 전 검증 결과
=========================

실행일: 2026-11-04. 환경: Windows, Python 3.12.14, NumPy 2.3.5, SciPy 1.18.1.

최신 새 정상/다른 시험대 미학습 검증: docs/EXTERNAL_BLIND_VALIDATION.rst.
정식 API는 새 580창 모두 보류, 정상 수락/종류 판정 0%로 적용 불가입니다.
범위 검사 제외 수치 시험도 베어링 변경 정상 이상 표시 100%, 종류 정답 44.29%로 실패했습니다.
다른 시험대 자료는 단위 미확인으로 물리 성능 자격을 입증하지 못했습니다.
새 자료로 학습·튜닝·보정하지 않았으며 기능 회귀 547개를 통과했습니다.

이전 고장 종류 개선: docs/FAULT_DISCRIMINATION_IMPROVEMENT.rst.
회귀 543개와 격리 휠 검증을 통과했습니다. 새 원본 고장 7개/560창에 대한
같은 자료 비교에서 기존 49.11%, 개선 99.82%입니다. 새 정상/새 설비 검증은 아닙니다.
학습·튜닝·변경 없이 동결 후 시험했으며 원본/접근/해시 감사를 통과했습니다.

이전 조건별 정상 기준 개선과 새로운 원본 기록 시험은
docs/CONDITIONED_IMPROVEMENT.rst를 참조하십시오. 기능 회귀 534개 통과와 별개로,
새 시험의 전체 정답률 51.88%/고장 종류 정답률 48.21%는 자동 확정에 부족합니다.

아래는 이전 단계의 검증 기록입니다. 이전 기능 회귀시험은 520개 통과입니다. 새 시험대의 source 취득 그룹 검증과
기존 Brito 4종 분류 결과는 범위가 다릅니다. 후속 1200 RPM 최종 시험에서
통합 시험용 후보는 11.04%/정상 오경보 100%로 실패했습니다.
docs/FINAL_CROSS_SPEED_VALIDATION.rst를 참조하십시오.

후속 분류기 개선 검증은 docs/CLASSIFIER_IMPROVEMENT.rst를 참조하십시오.
아래 24.94%는 수정 전 기록입니다. 수정 후 최종 시험은 63.69%이며 정상 시험
오분류가 남아 운영 사용은 여전히 불가합니다. 후속 회귀시험은 신규 10개를 포함해
총 498개가 통과했습니다.

스트림 초기화, 정상 기준의 장비 간 혼용 방지, HTTP 인증·출처·요청 형식,

검증에서 발견한 입력 방어·식별정보 연결·서비스 종료 문제를 수정했습니다.
네이티브 배열 API의 불필요한 목록 변환도 제거했습니다.

스트리밍 성능
--------------

각 120초 분량의 합성 신호를 실제 벽시계보다 빠르게 공급했습니다.
1초 창/0.25초 간격으로 조건마다 477개 창을 처리했습니다.
12 kHz 1채널의 창당 처리시간 p95는 6.83 ms,
25.6 kHz 4채널은 20.84 ms였습니다. 별도 20초 데이터 메모리 관찰의
후반 증가량은 각각 0.030/0.023 MiB였습니다.
이 결과는 이 PC의 합성 입력 처리 측정이며 센서 하드웨어 실시간 인증이나
수일 연속 가동 시험을 뜻하지 않습니다.

분류기 성능: 운영 사용 불충분
-----------------------------

Brito 시험 단위 분리: 학습 12회/5040개 창, 검증 4회/1680개 창,
최종 시험 4회/1680개 창. 검증 정답률 54.23%, 최종 시험 정답률 24.94%.
최종 시험은 대부분 looseness로 분류했습니다. 창들은 서로 독립된 시험이 아니므로
창 수를 독립 실증 횟수로 해석하면 안 됩니다. 이 결과에 맞춰 모델을 재조정하지
않았습니다. 분류기는 기본 비활성, operational_use=False이며 운전 판단에 부적합합니다.
FEMTO는 미래 자료를 바꿔도 과거 예측이 변하지 않는 인과성만 확인했습니다.
잔여수명 정확도 또는 '몇 시간 남음' 예측 성능은 검증하지 않았습니다.

배포 및 보안 범위
-----------------

휠의 격리된 가져오기, 핵심 RMS 계산, ISO 판정, 출처 JSON 포함을 확인했습니다.
휠과 소스 배포 패키지를 생성했습니다. 업로드 압축본은 자체 소스만 허용 목록으로
구성하며 PDF·원시 데이터·DB·외부 저장소 원문·로컬 실행 결과를 제외합니다.
압축본을 임시 폴더에 풀어 원본 자료 없이 35개 시험을 재실행하고,
그 폴더에서 휠과 소스 배포 패키지를 다시 만드는 데 성공했습니다.
Python 구문, 대표 자격증명 패턴, .gitignore 제외 규칙을 검사합니다.
NumPy 2.3.5/SciPy 1.18.1의 pip-audit 조회에서 알려진 취약점은 없었습니다.
이 조회는 전체 시스템 보안 감사가 아닙니다.

GitHub Actions에는 Windows/Linux 및 Python 3.11~3.13 검증을 설정했습니다.
원격 CI는 아직 실행하지 않았으며 로컬에서 확인한 환경은 위 Windows/Python 3.12입니다.
이 기록 작성 당시에는 라이선스/게시가 미정이었습니다. 공개본은 이후 MIT와 별도 배포 기록을 사용합니다.
