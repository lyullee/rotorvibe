헐거움·불평형 구분 개선과 새 고장 원본 시험
========================================

후속 새 정상/다른 시험대 무학습 평가에서는 일반화에 실패했습니다.
docs/EXTERNAL_BLIND_VALIDATION.rst 참조. 아래 99.82%는 원래 명시한 동일 시험대 범위의 결과입니다.

2026-11-04. 같은 새 고장 시험에서 기존 모델 275/560(49.11%),
개선 모델 559/560(99.82%)였습니다. 정상 판정기를 먼저 통과한 실제 연결 경로의 결과입니다.
이번 시험은 같은 시험대의 새 원본 기록/샘플링 도메인 분리 검증입니다.
독립 재설치·다른 설비·새 고장 강도 검증이 아니며, 정상 시험도 새로 포함하지 않았습니다.
operational_use=False와 기본 비활성을 유지합니다.

이전 실패의 구체적인 원인
-------------------------

이전에 개봉한 16 kHz/1200 RPM 결과를 이제 개발 자료로 재분석했습니다.
이것을 새 독립 시험으로 다시 부르지 않았습니다.

* 기존 선택 특징은 RMS와 아홉 개 회전 차수 에너지, 총 10개였습니다.
  충격성, 세밀한 반차수 분포, 고주파 대역 및 엔벨로프 형상은 분류 거리에 들어가지 않았습니다.
* 헐거움은 40창 중 37창이 거리 제한으로 종류 불명이었습니다. 제한을 없애고
  가장 가까운 후보만 고르더라도 20/40창만 맞았습니다. 특징/학습 대표성 문제도 있습니다.
  최근접 거리 중앙값 2.097은 해당 최근접 클래스 제한 중앙값 1.713보다 컸습니다.
* 강한 불평형 U3는 최근접 클래스가 40/40창 정답이었지만 전부 거리 제한에 걸렸습니다.
  거리 중앙값 1.927, 클래스 제한 1.673으로, 알려진 고장의 강도/속도 변화도 새 고장처럼
  거부하는 문제가 있었습니다. 반면 약한 불평형 U1은 최근접 후보도 15/40창만 맞았습니다.
* 한 원본을 한 중앙값으로 표현하면 한 기록 안의 시간 변화가 사라지고,
  단일 채널의 일부 차수만으로는 서로 유사한 기계 고장을 충분히 구분하기 어렵습니다.

이는 모델의 실패 기전을 확인한 것입니다. 특정 물리 원인을 유일하게 확정한 것은 아닙니다.
축 위상, 축방향/다방향 센서, 실제 헐거움 위치·간극을 추가 측정한 시험은 아닙니다.
감사 수치: output/fault_discrimination/previous_failure_diagnosis.json.

구현한 변경
-----------

기존 정상 판정기와 이전 동결 모델은 수정하지 않았습니다. 새로운 선택형 고장 종류 모듈을
그 뒤에 조립했습니다. 정상/보류 창은 고장 종류 모듈로 보내지 않습니다.

* 0.5X 간격으로 20X까지 40개 차수의 에너지와 반차수/고조파 합계를 계산합니다.
* RMS, crest factor, Pearson 첨도, impulse factor, 스펙트럼 엔트로피를 사용합니다.
* 0~1900 Hz의 일곱 대역별 상대 에너지와 여섯 차수의 엔벨로프 에너지를 추가했습니다.
* 모두 4 kHz 공통 대역으로 안티앨리어싱 변환한 2초 단일 채널 입력에서 계산합니다.
  기존 원시 신호/베어링 고주파 분석의 대역을 바꾼 것은 아닙니다.
* 총 61개 특징의 강건한 스케일을 원본별 대표값으로 학습합니다. 원본 하나를 시간순
  네 구간 대표값으로 표현해 시간 변화도 남기고, 파일마다 같은 수의 대표값을 사용합니다.
* 고장별 최근접 대표값을 비교하고, 다른 원본끼리의 거리를 이용한 경험적 범위 제한을 둡니다.
  같은 파일의 이웃 창을 독립 보정 자료로 사용하지 않았습니다.
  동률·범위 밖은 종류 불명으로 남습니다. 거리값은 고장 확률이 아닙니다.

속도 거리 가중치도 후보에 포함했지만 개발 성능을 낮춰 제외했습니다.
최종 선택은 morphology, RPM penalty=0, margin=0입니다. margin=0에서도
정확한 동률과 거리 범위 밖 거부는 유지합니다. 시험 결과를 보고 제한을 푼 것이 아닙니다.

추가 자료와 원본 분리
--------------------

원 출처: https://data.mendeley.com/datasets/53vtnjy6c6/1 (DOI 10.17632/53vtnjy6c6.1),
Seongjae Lee, Taewan Kim, Taehyoun Kim, University of Seoul, CC BY 4.0.
설명 논문: https://pmc.ncbi.nlm.nih.gov/articles/PMC11437749/.

교정 인증서나 독립 재설치 식별자는 제공되지 않습니다.

이전에 수집하지 않았던 8 kHz 단일 회전체 고장 원본 MAT 42개,
810,891,430 bytes(약 811 MB)를 새로 모으고 모두 제공자 SHA256을 확인했습니다.

* 600/800/1000/1400/1600 RPM의 새 35개는 개발·학습 자료입니다.
* 1200 RPM의 새 7개(L, M1~M3, U1~U3)는 다운로드 전 원본 단위로 최종 시험에 배정했습니다.
  수집 시 수치 배열을 열지 않았고 학습/튜닝/특징 선택/스케일 계산에서 제외했습니다.
* 이전 16 kHz 시험을 포함한 기존 54개는 이미 개봉한 개발 자료로 명시했습니다.
  따라서 최종 시험과 같은 고장 강도·1200 RPM의 16 kHz 기록이 학습에 있습니다.
* 개발 원본 총 89개 중 정상 12개는 고장 종류 학습에서 제외했습니다.
  고장 77개/4480개 창으로 최종 종류 모듈을 학습했습니다.
  정상 판정기는 이전에 동결한 정상 기준 모델을 그대로 사용합니다.
* 새 최종 시험은 고장 7개/각 160초, 총 1120초/비중복 2초 창 560개입니다.
  이번 새 데이터에는 미개봉 정상 원본이 없습니다. 기존 정상 자료를 새 정상 시험으로
  재포장하지 않았으며, 새로운 4종 전체 정확도나 정상 오경보율을 제시하지 않습니다.

data/fault_discrimination/plan.json에 역할을 수집 전에 고정했고 manifest.json에
출처·용량·체크섬 확인 결과를 기록했습니다. 원본 자료는 소스 ZIP에 포함하지 않습니다.

학습·튜닝 절차
--------------

차수 특징만/전체 형태 특징, 속도 가중치 0/1/4, margin 0/0.05의 12개 후보를 비교했습니다.
1000 RPM과 1400 RPM을 각각 전체 속도 단위 검증으로 사용했고, 각 속도의
8 kHz와 16 kHz 원본을 함께 학습에서 제외해 다른 수집률의 같은 속도가 새지 않게 했습니다.
최종 후보 선택 기준은 두 개발 fold의 평균 Macro-F1입니다.

차수만 사용한 RPM 가중치 0/margin 0 후보의 평균 Macro-F1은 52.72%,
전체 형태 특징의 같은 설정은 86.41%였습니다. 전체 특징 후보의 개발 정답률은
1000 RPM 90.71%, 1400 RPM 78.93%였습니다. 특징 보완의 개발 근거이며,
고장 강도/속도 대표성을 추가한 효과와 분리한 최종 시험 인과 추정은 아닙니다.
개발 fold 자료는 후보 선택에 쓰였고 최종 재학습에도 포함되어 독립 최종 성능이 아닙니다.

새 원본 시험 결과
-----------------

두 모델을 동일한 새 560개 창에 적용했습니다. 기존 정상 판정기가 이상이라고 확인한
경우에만 새 종류 모듈을 호출한 경로를 주 결과로 삼았습니다. 모든 창이 기존 판정기에서
이상으로 감지되어, 고장임을 전제한 종류 결과와 실제 연결 경로 결과가 이번에는 같습니다.
보류·종류 불명·정상 오판은 모두 오답으로 집계했습니다.

원본별 최다표는 개선 모델에서 7/7개가 정답입니다. 헐거움↔불평형 직접 혼동은
기존 모델 2개 창에서 개선 모델 0개 창으로 줄었습니다. 이전 오답 중 285개를 고쳤고,
기존 정답 중 정렬불량 M2 한 개 창을 불평형으로 바꾼 퇴행이 있습니다.

여기서 49.11%와 99.82%만 같은 자료에 대한 비교입니다.

독립성 감사와 한계
-----------------

원본 7개 접근 기록과 560개 창 위치를 독립 재집계했고 누락·중복이 없었습니다.
새 원시 Data 해시는 source 89개 및 다른 최종 원본과 중복되지 않았습니다.
같은 고장/속도의 학습 16 kHz 원본과 새 8 kHz 원본 사이의 1~3 kHz 잡음 상세
최대 상관도는 0.075~0.183으로 사전 기준 0.98 미만이었습니다.
이는 동일/재표본화 파형 중복을 찾는 보조 검사이며 독립 재설치의 증명이 아닙니다.
모델·코드·역할 해시는 시험 후에도 같았고, 새 결과에 맞춘 재학습/재튜닝은 하지 않았습니다.

560개 창은 560번의 독립 실험이 아닙니다. 특히 헐거움 최종 원본은 하나이고,
불평형/정렬불량은 강도별 하나씩입니다. 같은 시험대의 같은 강도를 다른 수집률에서
측정한 기록을 분리한 검증이므로 높은 정답률을 새 설비 일반화나 현장 확진율로 해석할 수 없습니다.
복합 고장, 다른 베어링, 가변 속도, 다른 센서 설치, 새로운 부하도 이번 범위 밖입니다.
정상 판정기는 바꾸지 않았지만 새 정상 자료가 없으므로 정상 오경보 성능을 새로 보증하지 않습니다.

Python API와 회귀 검증
---------------------

::

   import json
   from pathlib import Path
   from vibration.fault_discrimination import FaultDiscriminator

   profile = json.loads(Path('output/fault_discrimination/frozen.json').read_text())
   model = FaultDiscriminator(profile)
   # 먼저 외부 정상 판정기에서 이상으로 확인한 2초 단일 채널 원시 배열만 전달.
   candidate = model.analyze(raw, 8000, 1200, scope={
       'asset_id': 'UOS_MOCHU6204',
       'condition_id': 'steady_bearing_healthy', 'unit': 'g'})

독립 특징 API fault_features, 학습 API fit_fault_discriminator, NumPy 배열 추론 API
FaultDiscriminator, 정상 단계 뒤 연결하는 FaultDiscriminationStage를 제공합니다.
예: examples/fault_discrimination_composition.py. 서버나 DB가 필요하지 않으며,
이 모듈 자체는 정상을 식별하는 분류기가 아닙니다. 기존 레지스트리의 모델을 자동 교체하지 않습니다.
프로파일과 실제 장비·조건·단위가 일치해야 하며 UOS 모델을 이름만 바꿔 현장에 적용하면 안 됩니다.

입력/계산/물리 불변량/동률·범위 밖 보류/원본 그룹/JSON/분석 단계 연결 시험 9개를 추가했습니다.
이식 가능한 시험 90개, 구현 58개, 물리 32개, ISO 363개, 합계 543개를 통과했습니다.
기존 HTTP 시험의 첫 실행에서 Windows 연결 중단 1건이 있어 최초 로그를 보존했고,
코드 변경 없이 전체 90개를 다시 실행해 통과했습니다. 격리 휠 검증도 통과했습니다.
예측 시험 결과와 코드 회귀 통과는 별개입니다.
