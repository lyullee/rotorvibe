새 정상·다른 시험대 미학습 검증: 적용 실패
========================================

2026-11-04. 새 자료 43개 원본/580개 창을 학습·튜닝·정상 기준 보정에 사용하지 않고
기존 모델과 코드 그대로 평가했습니다. 결론은 새 장비/베어링에 대한 무학습 적용 불가입니다.
정식 API는 모두 보류했습니다. 별도 수치 스트레스 시험에서도 일반화에 실패했습니다.
이전 99.82%는 같은 시험대·베어링·고장 강도의 원본 기록 분리 성능으로 범위를 제한해야 합니다.

학습 및 이전 시험과의 분리
-------------------------

새 43개 원본은 모두 test_only입니다. 이전 데이터 폴더와 분리해 보관했습니다.
모델 학습/기존 시험의 원시 Data 해시 96개와 새 단일 채널 Data 해시를 비교했고,
새 원본끼리도 정확히 같은 파형이 없었습니다. 새 원본 접근 43개/580개 창 위치를 기록했습니다.
이것이 다른 세션에서 절대 중복이 없다는 통계적 증명은 아니지만, 명시한 시험대 출처와
원본 분리 및 정확한 파형 중복 여부를 감사한 것입니다.
원본 창은 서로 상관돼 있으므로 580번의 독립 현장 실험으로 해석하지 않습니다.

정식 API 결과: 판정 커버리지 0%
-----------------------------

실제 asset_id, condition_id, 단위, 채널 이름과 원래 샘플링률을 전달했습니다.
새 시험대를 UOS 6204 장비로 이름만 바꾸지 않았습니다.

* UOS30204의 520개 창은 정상 기준 적용 범위 불일치로 보류했습니다.
* UFRJ의 60개 창은 원래 50 kHz 입력이 기존 정상 판정기의 허용 수집률 밖이라 보류했습니다.
  자산/단위/채널/정상 기준도 기존 프로파일과 맞지 않습니다.
* 정상 270창에서 정상 수락 0, 보류 270, 이상 표시 0입니다.
* 고장 310창에서 종류 정답 0, 종류 판정 0입니다. 보류를 오답으로 집계하면 0%입니다.

이 결과는 보류 계약이 작동했음을 보여 줍니다. 정상 오경보율 0%를 검증했다는 뜻은 아닙니다.
판정한 정상 창이 없어 판정 가능한 영역의 오경보율은 측정 불가(null)입니다.
정상 수락률과 고장 종류 판정률도 모두 0%여서 운영 성능 자격 검증은 불합격입니다.

별도 수치 스트레스 시험
----------------------

정식 API 보류만으로 특징/모델의 일반화 상태를 알 수는 없어, 사전 명시한 별도 오프라인
계산에서 자산/채널 적용 범위 검사를 제외하고 동결된 수치 계산만 실행했습니다.
이 계산은 scripts/external_blind_metrics.py에만 있으며 제품 API의 보호 조건을 바꾸지 않았습니다.
모든 출력에 offline_scope_bypass=True, operational_use=False를 기록했습니다.

기존 공통 4 kHz 변환과 특징식, 정상 속도 기준의 허용 오차, 정상 점수와 임계값,
종류 대표값과 거리 제한은 그대로 사용했습니다. RPM은 명목 메타데이터를 그대로 쓰고
정상 기준에 맞도록 반올림하거나 진동 피크로 고쳐 잡지 않았습니다.
새 정상의 중심·진폭·분산을 맞추는 보정도 하지 않았습니다.

UOS30204: 단위 g가 확인된 베어링 변경 스트레스
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

* 정상 이상 표시 240/240(100%), 정상 수락 0/240입니다.
* 정상 원본 6/6개에 이상 표시가 있었습니다.
* 고장 종류 정답 124/280(44.29%), 보류 0입니다.
* 헐거움 2/40(5%), 불평형 2/120(1.67%), 정렬불량 120/120(100%)입니다.
* 헐거움 38창과 불평형 117창을 정렬불량으로 표시했습니다.

단순히 판단 제한 때문에 점수가 낮은 것이 아닙니다. 범위 검사를 제외하면 새 베어링의
정상도 기존 정상 기준 밖에 놓이고, 고장 특징은 정렬불량 쪽으로 체계적으로 치우칩니다.
같은 기계 시험대에서도 베어링/전달 경로가 달라지면 정상 기준과 특징 분포가 바뀌는 실패를
확인했습니다. 100%는 강제 전이 수치 시험의 창별 이상 표시율이며 현장 운영 경보율이 아닙니다.

UFRJ: 다른 시험대, 단위 미확인 스트레스
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

저장 단위를 확정할 수 없어 동결 전에 원시 값 x1과 x10을 모두 고정했습니다.
x10은 만약 원시 값이 V이고 100 mV/g 조건이라면 해당하는 가정일 뿐, 교정값으로 확정하지
않았습니다. 정답을 보고 좋은 배율을 고르지 않았으며 두 경우를 모두 보존했습니다.

두 가정의 집계 결과는 같았습니다.

* 정상 30창 중 이상 표시 4, 속도 기준 없음으로 보류 26, 정상 수락 0입니다.
* 전체 정상 창 대비 이상 표시는 4/30(13.33%)이나 판정 커버리지는 4/30뿐입니다.
  판정한 정상 4창은 모두 이상이므로 판정한 창 중 비율은 100%입니다.
  이 4창은 정상 원본 2개에서 나왔습니다.
* 고장 30창 중 연결 경로에서는 보류 18, 종류 불명 12입니다. 종류 정답 0/30입니다.
* 고장임을 전제해 종류 모듈만 실행해도 30창 모두 학습 거리 범위 밖으로 종류 불명이었습니다.

위 수치는 미확인 단위에서 수행한 수치 민감도 시험으로, 교정된 물리 오경보율이나
범위 내 현장 고장 종류 정확도로 인용하면 안 됩니다. 다른 시험대에서 헐거움은 미평가입니다.
UOS 베어링 변경 결과와 UFRJ 다른 시험대 결과를 하나의 물리 정답률로 합치지 않았습니다.

판단과 남은 제약
----------------

기존 99.82% 결과를 다른 장비/베어링 일반화 성능으로 확대할 근거가 없습니다.
현재 공개 API는 해당 장비의 정상 기준이 없는 환경에서 자율 진단을 제공하지 않습니다.
보류를 정상으로 간주하거나 장비 이름을 바꿔 범위 검사를 통과시키면 안 됩니다.

운영 가능한 새 정상 오경보율과 다른 설비의 고장 정확도는 이번 조건에서 입증하지 못했습니다.
이것은 검증 실패 결과이지 평가가 정상 통과했다는 뜻이 아닙니다.
이번 요청대로 새 데이터에 대한 학습·튜닝·보정을 하지 않았고, 시험 후에도 동결 상태를 유지했습니다.
후속 개선에 이 데이터를 사용하면 이제 개발 자료가 되므로 다시 다른 미사용 최종 시험이 필요합니다.
